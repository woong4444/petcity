PetCity Oracle 전체 실행 순서
================================

전제
----
- 비어 있는 Oracle 사용자(스키마)에서 처음부터 생성하는 기준입니다.
- 각 파일은 DBeaver의 'SQL 스크립트 실행' 방식으로 한 파일씩 실행합니다.
- URL 문자열에 '&'가 포함되어 있습니다.
  SQL Developer/SQLcl을 사용할 때는 실행 전에 SET DEFINE OFF를 한 번 입력하세요.
- 파일 하나가 실패하면 다음 파일로 넘어가지 말고 해당 오류를 먼저 해결하세요.

데이터 배치 기준
----------------
- 회원 데이터: 생성 코드가 짧아 01-00에 포함
- 동물/서비스/진료과목 기준 데이터: 필수 소량 데이터라 02-00에 포함
- 병원 및 병원 관계 데이터: 데이터가 많아 04-01 ~ 04-04로 분리
- 회원 OWNER 권한 동기화: 병원 입력 후 실행하도록 04-05로 분리
- 게시판/댓글/이미지/조회 이력: 데이터가 많고 의존 순서가 있어 07-01 ~ 07-04로 분리
- 챗봇 카테고리와 FAQ 연결: 소량이며 게시판 데이터 이후 실행하므로 08-00에 포함
- 메인 배너 4개: 소량이라 10-00에 포함

중요한 정리
------------
- 병원 관계 데이터에는 HOSPITAL_ID 재매핑표가 반영되어 있습니다.
- 게시판 댓글·이미지·조회 이력은 BOARD_ID를 고정하지 않고
  게시글 종류 + 제목 + 작성자 LOGIN_ID로 게시글을 찾습니다.
- 조회 이력 원본에서 게시글 제목과 일치하지 않던 2건을 실제 제목으로 맞췄습니다.
- 08 챗봇 SQL에 단독으로 들어 있던 'x' 문자를 제거했습니다.
- 병원장 신청의 HOSPITAL_ID FK는 ON DELETE SET NULL입니다.
- CK_OWNER_REQUEST_HOSPITAL은 APPROVED + HOSPITAL_ID NULL을 허용하므로
  병원 하드딜리트 후 신청 이력만 남길 수 있습니다.
